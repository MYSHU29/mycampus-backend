Tentang

Aplikasi Akademik Digital

MyCampus Mobile adalah aplikasi akademik digital yang dirancang untuk mempermudah mahasiswa dalam mengakses informasi perkuliahan secara real-time. Mulai dari data mahasiswa, prestasi akademik dan non-akademik, pembayaran SPP, pengambilan mata kuliah, hingga peminjaman buku — semuanya tersaji dalam satu genggaman.
Aplikasi ini dibangun dengan Flutter untuk antarmuka yang responsif dan Laravel 13 di sisi backend. Didukung oleh sistem evaluasi Fuzzy Logic untuk analisis performa mahasiswa secara otomatis, serta sistem RBAC (Role-Based Access Control) untuk keamanan hak akses per peran.

Tentang & Mengapa Memilih

Mengapa MyCampus?

Sistem informasi akademik yang memusatkan pengelolaan data mahasiswa, SPP, matakuliah, buku, dan prestasi — dengan penilaian kualitas prestasi otomatis berbasis Fuzzy Logic.

Latar Belakang

Data akademik tersebar di file & spreadsheet sehingga tidak sinkron, verifikasi prestasi manual dan lambat, serta tidak ada jejak audit. MyCampus memusatkan seluruh data akademik dalam satu sistem real-time.

Tujuan

Memusatkan & mempercepat pengelolaan data akademik: input terpusat, verifikasi prestasi berbasis Fuzzy, dashboard statistik otomatis, dan akses mobile di mana saja.

RESTful API untuk Aplikasi Mobile

API berbasis JSON & token Sanctum yang dipakai aplikasi Android Flutter dan integrasi pihak ketiga.

MetodeEndpointDeskripsi
POST/api/loginAutentikasi & menerbitkan token Sanctum
POST/api/registerDaftar akun mahasiswa baru (role mahasiswa)
GET/api/dashboardStatistik & ringkasan dashboard
GET/POST/api/mahasiswaDaftar & buat data mahasiswa (paginasi, pencarian)
GET/POST/api/prestasiDaftar & buat prestasi mahasiswa
POST/api/prestasi/{id}/verifikasiVerifikasi prestasi (approval queue)

GET/api/prestasi-laporanLaporan prestasi untuk ekspor
GET/api/download-apk/{arch}Unduh APK per arsitektur (rate-limited 10/menit)
Instalasi & Kebutuhan Sistem

Mulai Jalankan Sendiri

Panduan instalasi singkat dan spesifikasi sistem minimum serta rekomendasi.

1
Clone Project
git clone mycampus-backend lalu masuk ke direktori proyek.
2
Install Dependency
Jalankan composer install untuk seluruh dependensi backend.
3
Konfigurasi Environment
Salin .env.example ke .env, isi kredensial MySQL & jalankan php artisan key:generate.
4
Migrasi Database
Jalankan php artisan migrate --seed untuk skema, roles, permissions, & data awal.
5
Build Frontend
npm install && npx vite build untuk aset CSS/JS (Tailwind v4).
6
Jalankan Server & APK
php artisan serve / arahkan docroot ke public; build APK Flutter per-ABI.

Keamanan & Performa

Dibangun dengan Standar Terbaik

Lapisan keamanan berstandar Laravel dan optimasi performa untuk operasional akademik.

Fitur Keamanan

  • ✓Authentication — session (web) & token Sanctum (mobile)
  • ✓Role & Permission — middleware role/permission per modul, admin bypass
  • ✓Password Hash — bcrypt pada penyimpanan kata sandi
  • ✓CSRF Protection — token CSRF otomatis di semua form web
  • ✓XSS Prevention — escaping output Blade & validasi input
  • ✓SQL Injection Prevention — query Eloquent berparameter
  • ✓Rate Limiting — unduh APK 10 kali/menit per pengguna
  • ✓Activity Log — audit setiap aksi, filter, ekspor & retensi 90 hari

Optimasi Performa

  • ✓Pagination — daftar data & laporan dipecah per halaman
  • ✓Optimized Query — index & eager loading untuk relasi
  • ✓Caching — query dashboard & data sering di-cache
  • ✓Asset Minification — CSS/JS di-build via Vite
  • ✓Dashboard Real-time — statistik dihitung langsung dari database
  • ✓API Ringan — respons JSON untuk aplikasi mobile hemat data
