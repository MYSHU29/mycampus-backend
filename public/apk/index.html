Tentang

Aplikasi Akademik Digital

MyCampus Mobile adalah aplikasi akademik digital yang dirancang untuk mempermudah mahasiswa dalam mengakses informasi perkuliahan secara real-time. Mulai dari data mahasiswa, prestasi akademik dan non-akademik, pembayaran SPP, pengambilan mata kuliah, hingga peminjaman buku — semuanya tersaji dalam satu genggaman.
Aplikasi ini dibangun dengan Flutter untuk antarmuka yang responsif dan Laravel 13 di sisi backend. Didukung oleh sistem evaluasi Fuzzy Logic untuk analisis performa mahasiswa secara otomatis, serta sistem RBAC (Role-Based Access Control) untuk keamanan hak akses per peran.

Tentang & Mengapa Memilih

Kenapa RingkasURL?

Solusi atas tautan panjang dan berantakan agar lebih profesional serta mudah dibagikan — membantu individu dan bisnis mengoptimalkan strategi tautan mereka.

Latar Belakang

Tautan panjang dan berantakan sulit dibagikan, rawan salah ketik, dan sulit diukur. RingkasURL mengubahnya menjadi tautan pendek yang profesional, terukur, dan dapat dipantau.

Tujuan

Membantu individu dan bisnis mengoptimalkan strategi tautan mereka: membagikan link yang ringkas, melacak setiap klik, dan mengambil keputusan berbasis data.

Instalasi & Kebutuhan Sistem

Mulai Jalankan Sendiri

Panduan instalasi singkat dan spesifikasi sistem minimum serta rekomendasi.

1
Clone Project
git clone repositori lalu masuk ke direktori ringkasurl.
2
Install Dependency
Jalankan composer install untuk seluruh dependensi backend.
3
Konfigurasi Environment
Salin .env.example ke .env, isi kredensial database & APP_KEY.
4
Migrasi Database
Jalankan php artisan migrate --seed untuk skema & data awal.
5
Jalankan Server
php artisan serve (lokal) atau arahkan Apache/Nginx ke folder public.
6
Verifikasi
Buka URL aplikasi, login, buat tautan uji, dan jalankan php artisan test.

Keamanan & Performa

Dibangun dengan Standar Terbaik

Lapisan keamanan berstandar Laravel dan optimasi performa untuk skala besar.

Fitur Keamanan

  • ✓Authentication — login berbasis session & token Sanctum
  • ✓Role & Permission — middleware RBAC untuk setiap modul
  • ✓Password Hash — bcrypt pada penyimpanan kata sandi
  • ✓CSRF Protection — token CSRF otomatis di semua form
  • ✓XSS Prevention — escaping output Blade & validasi input
  • ✓SQL Injection Prevention — query Eloquent berparameter
  • ✓Rate Limiting & validasi tautan berbahaya

Optimasi Performa

  • ✓Pagination — daftar tautan & laporan dipecah per halaman
  • ✓Caching — redirect populer & query sering di-cache
  • ✓Lazy Loading — resource & gambar dimuat saat dibutuhkan
  • ✓Optimized Query — index & eager loading untuk relasi
  • ✓Asset Minification — CSS/JS di-minify & di-concat
  • ✓CDN — distribusi aset statis lebih cepat
Studi Kasus (Dampak Nyata)

Sebelum vs Sesudah Menggunakan MyCampus

Perbandingan permasalahan umum pengelolaan data akademik sebelum memakai MyCampus dibanding hasil setelahnya.

#❌ Sebelum✔ Sesudah
1Data mahasiswa, SPP, dan matakuliah tersebar di file & spreadsheet sehingga sering tidak sinkron.Data akademik terpusat — mahasiswa, SPP, matakuliah, dan buku dalam satu sistem real-time.
2Verifikasi prestasi manual dan lambat, rawan kehilangan berkas.Verifikasi cepat dengan approval queue dan penilaian kualitas otomatis (Fuzzy Logic).
3Informasi akademik hanya bisa diakses dari kampus atau kantor.Akses mobile real-time melalui aplikasi Android Flutter di mana saja.
4Laporan dan statistik dihitung manual, memakan waktu lama.Dashboard otomatis dengan grafik prestasi per jenis & tingkat, tren, dan capaian verifikasi.
5Hak akses data antar petugas tidak terkontrol.RBAC ketat (admin/operator/dosen/mahasiswa) dengan pembatasan hak akses per modul.
6Tidak ada jejak perubahan data (siapa dan kapan).Activity log lengkap untuk setiap aksi di seluruh modul, mudah diaudit.
